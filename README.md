# OpenLab / PromptLab

PromptLab is a public, multilingual generated mirror of content approved in
Payload CMS. CMS records and their versioned editorial and rights decisions are
the content source of truth. GitHub provides a transparent, attributable and
versioned public projection.

The public catalog is currently awaiting its first approved CMS snapshot. The
existing 35 imported community records remain `review_required` and are not
part of this repository.

## Contribute

Use the Issue Forms for an original or authorized Prompt, a community
nomination, a correction, a translation or a takedown request. A maintainer's
`approved` label authorizes intake of that exact Issue revision into CMS; it is
not a CMS publication or rights approval.

Content contributors do not edit generated Markdown through pull requests.
Code, workflow, schema, license and policy changes continue to use reviewed
engineering pull requests. See [CONTRIBUTING.md](CONTRIBUTING.md), the
[content contract](docs/CONTENT-CONTRACT.md) and the
[security policy](SECURITY.md).
