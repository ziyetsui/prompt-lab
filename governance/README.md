# Human-approved content-rights clearances

`rights-clearances.json` is a repository-specific publication gate kept separate from the canonical Prompt Markdown contract. A `published` and `indexable` Prompt cannot enter the generated public catalog unless a human-reviewed clearance exists for the exact immutable ID and locale.

Every clearance needs a concrete basis, reviewer, timestamp, evidence URL, and license or permission reference. Agents must not create, infer, or approve these records. The empty initial registry is intentional.
